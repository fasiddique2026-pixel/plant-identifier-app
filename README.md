# 🌿 Quick Plant Identifier AI

An AI-powered web application that identifies plant species from uploaded photos, evaluates plant health, and offers instant care recommendations.

🚀 **Live App:** [quick-plant-ai.streamlit.app](https://quick-plant-ai.streamlit.app)

---

## ✨ Features
* 🔍 **Instant Species Identification:** Recognizes houseplants, garden flora, and wildflowers from a single photo.
* 🩺 **AI Health Diagnostics:** Analyzes leaves for diseases, pest damage, and nutrient deficiencies.
* 💡 **Tailored Care Advice:** Provides actionable watering, lighting, and soil suggestions to restore plant health.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **AI Engine:** Groq API
* **Language:** Python
